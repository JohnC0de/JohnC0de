### Hey, I'm João

Right now I'm building [t3code-mods](https://github.com/JohnC0de/t3code-mods): mods for T3 Code that hot reload, from CSS and React tweaks to patches and backend code, on Windows and Linux.

Before that:

* [Dev Tray](https://github.com/JohnC0de/dev-tray), a tiny Windows tray app that answers one question: what's running on my machine, and which project does it belong to? One click to open it, one click to kill it.
* Biologists doing taxidermy were making specimen labels by hand in Word. [bio-tag](https://github.com/JohnC0de/bio-tag) generates the whole printable sheet for them.
* I wanted to know what actually happens behind "Sign in with...", so I started an [OAuth2 server with Fastify](https://github.com/JohnC0de/fastify-oauth) instead of just reading about it.
* I play Magic: The Gathering, so naturally I started [a deck builder](https://github.com/JohnC0de/scryfall-personal) instead of actually playing.

There's also Skrills, a desktop app that isn't ready to be talked about yet, and some late night [Godot experiments](https://github.com/JohnC0de/game-zero) to see if I can finish a game before it finishes me.
