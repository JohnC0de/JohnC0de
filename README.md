# Hey, I'm João Carlos 👋

Full-stack developer from Brazil who likes building things that solve real problems — from developer tools to desktop apps.

## What I'm working on 🚀

- **[Dev Tray](https://github.com/JohnC0de/dev-tray)** — *localhost, organized.* A tiny Windows tray app that auto-detects your local dev servers, maps each one to its Git repo and branch, and lets you open or kill it in one click.
- **Skrills** — a desktop app in active development ([public releases](https://github.com/JohnC0de/skrills-releases)).
- **[game-zero](https://github.com/JohnC0de/game-zero)** — exploring game development with the Godot Engine.

Currently exploring: Electron, TanStack Start, Bun, Drizzle ORM and Godot.
